# VRC Project Setup

Create and manage VRChat Unity projects on Windows.

**Windows x64 · Beta**

## Download

**[⬇ Download for Windows](https://github.com/dummics/vrchat-project-setup/releases/tag/v0.2.6-beta.2)**

Open the newest release and click **Download this version**. Run the installer; the same EXE installs or updates the app.

## Get started

1. In **Settings**, select Unity **2022.3.22f1** and your projects folder.
2. Create a project, add an existing one or import a `.unitypackage`.
3. Choose your packages or a preset, review and apply.

Updates download in the background and install on the next launch. You can also update from the version button.

Getting started

  • Run the Windows installer to install or update VRC Project Setup. The app opens automatically.
  • Choose your Unity Editor and projects folder. Keep Unity Hub, the required build modules and VRChat Creator Companion installed.
  • Drop an avatar package, review the preset and import. Existing projects stay under your control.

The app checks GitHub for updates. When one is available, install it from the version menu after finishing your work.
